# 2026-06-21

## 修复：爷爷精灵瞬移 Bug（两次迭代）

**文件**: `OldFarmer/GrandpaTillerBehavior.cs`

**现象**: 玩家从其他地图回到农场、走进农田区域时，爷爷精灵会瞬移到一个遥远的旧坐标再慢慢移过来。

**第二次修复**: 上述修复不够完整。根本原因是：玩家在农场内从无耕地区域走到有耕地区域时，`Orbiting → MovingToTarget` 切换，`WorldPosition` 是上次 `IsTilling` 结束时的旧坐标，导致精灵闪现。真正的修复点在 `TickOrbiting`：在 `TransitionTo(MovingToTarget)` 之前将 `WorldPosition = player.getStandingPosition()`，确保每次开始耕地任务时精灵都从玩家身边出发。`wasOnFarm` 标志保留但仅用于离开农场的状态重置，不再负责位置初始化。

## 改动：蓄力直接显示最终阶段

**文件**: `OldFarmer/GrandpaTillerBehavior.cs`

去掉了分阶段蓄力扩展逻辑（原来 `t<0.2→stage1`、`t<0.4→stage2` 等），改为在整个蓄力期间 `currentStage = 4`（9×9 全范围），enter 块也同步改为 `currentStage = 4`。`t` 变量保留，仍用于震动动画。

## 新功能：爷爷牵引半径（Leash）

**文件**: `OldFarmer/GrandpaTillerBehavior.cs`

新增常量 `LeashRadius = 640f`（10 格）。在 `Update()` 状态机执行前，若爷爷与玩家距离超过该值，立即放弃当前任务回到 `Orbiting`，`WorldPosition` 也拉回玩家身边。玩家再次靠近耕地时爷爷会重新启动耕地逻辑。

## 调整：爷爷绕圈改为完整水平正圆

**文件**: `OldFarmer/GrandpaSpiritOrbiter.cs`

将 `IsometricYScale` 从 `0.55f` 改为 `1.0f`，`OrbitRadius` 从 `56f` 增大到 `80f`，使爷爷在屏幕上走完整的正圆轨迹。但世界坐标计算无法消除等距投影变形，屏幕上仍然是椭圆。

**最终修复**：改为直接在屏幕坐标计算轨迹（先把玩家世界坐标转为屏幕坐标，再加 `cos/sin * OrbitRadius` 偏移），绕过世界坐标投影，屏幕上始终呈现真正正圆。删除了 `IsometricYScale` 常量。

## 修复：蓄力开始第一帧闪烁 9×9 高亮

**文件**: `OldFarmer/GrandpaTillerBehavior.cs`

`currentStage` 蓄力结束后停在 `4`，下次进入 `ChargingHoe` 第一帧 `TickChargingHoe` 未执行，`HighlightDrawer` 用旧值 `4` 画了一帧 9×9 大范围，第二帧才缩回 `1`，产生闪烁。修复：在 `TransitionTo(ChargingHoe)` 的 enter 块加 `currentStage = 1`。

**深层修复**：`chargeTick` 的重置原来写在 `TickMovingToTarget` 里，如果未来有其它路径进入 `ChargingHoe` 就会带着旧的 `chargeTick`，导致第一帧 `t` 可能很大，stage 直接跳到 4。将 `chargeTick = 0` 也移进 `TransitionTo(ChargingHoe)` 的 enter 块，同时蓄力完成时加 `currentStage = 0` 清除高亮，彻底消除各类闪烁。
