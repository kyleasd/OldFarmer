## 砍树模块 Bug 修复

- **农场检测修复**：`Name != "Farm"` → `!IsFarm`，修复非标准农场（森林/海滩/河边等）模块完全不运行的问题。同时修复了 `GrandpaTillerBehavior.cs` 中存在的同一问题。
- **砍树逻辑修复**：原来 `tree.health.Value = -100f` 无法触发游戏的砍树机制（动画、掉落、实际移除）。改为两阶段：成树 → 设置 `stump.Value = true` + `health = 0`，由游戏的 `tickUpdate` 在下帧处理树倒动画并移除树桩；已有树桩 → 直接从 `terrainFeatures` 移除。
- **添加 SMAPI 诊断日志**：`WoodcuttingModule` / `GrandpaWoodcutterBehavior` 通过 `SetMonitor()` 注入 IMonitor，每 3 秒输出一次扫描结果和状态信息。日志级别 Info，SMAPI 控制台可见。
- **FarmHouse 误判修复**：`FarmHouse`（农舍内部）的 `IsFarm` 意外返回 `true`，导致砍树模块在室内就扫描（找不到树），且 `_wasOnFarm` 被早早设为 `true`，走到户外农场时不再重新扫描。修复：`IsFarm` → `IsFarm && IsOutdoors`，同时修正了 `GrandpaTillerBehavior.cs` 的同样缺陷。

## 砍树机制改为逐次掉血

- **问题**：原来斧头碰到树 → `health=0 + stump=true`，树瞬间消失，不像"砍树"。
- **新机制**：每击 3 伤害，树 10 血 → 4 次砍倒变树桩；树桩 4 血 → 2 次砍掉移除。加入 12 tick 命中 CD（`LastHitTick` 字典）防止同一 tile 每帧多打。
- **斧头放大**：`AxeScale` 3f → 6f（96×96 px），`HitRadius` 40 → 60。
- **砍树时间延长**：`ChopDurationTicks` 60 → 120（每目标 ~2 秒，确保 4+ 击足以砍倒一棵树）。
- **扫描范围扩大**：`ScanRadius` 从 6 → 25（51×51 区域），确保覆盖更大范围的树木。
- **诊断日志增强**：首次进入 Orbiting 状态立即输出扫描结果（总树数/可砍数/玩家位置/场景名），后续每 2 秒刷新。`CountTrees()` 新增分别统计 terrainFeatures 中所有 Tree 和可砍 Tree 的数量。

## 砍树改用 performToolAction（原版砍树动画）

- **问题**：第二次改逐次掉血后仍无动画，只是数值变化。
- **根因**：直接修改 `tree.health` / `tree.stump` 绕过了游戏的砍树系统。
- **修复**：`WoodcutterExecutor.ChopAtPosition` 改为调用 `tree.performToolAction(axe, 0, tilePos)`，使用 Steel Axe（UpgradeLevel=2，3 伤害/击）。游戏原生会触发：砍树音效、木屑粒子、树晃动画、倒地动画、木材掉落。
- **命中 CD** 保持 15 tick，防止斧头跟树重叠时每帧重复触发 performToolAction。
- **砍树时间** `ChopDurationTicks` 120 → 180（~3 秒，~6 圈旋转），确保足够命中次数砍倒树+移除树桩。
- **AxeScale 保持 6f**（96×96 px），HitRadius 保持 60。

## 砍树 0 伤害修复 + 诊断日志

- **问题**：砍树动画有了（音效+木屑），但树不倒。
- **根因**：`performToolAction` 内部通过 `t.getLastFarmerUse()` 获取玩家来计算伤害。创建 Axe 后没设 `lastUser`，返回 null → 伤害 = 0。
- **修复**：每次调用 `performToolAction` 前设 `axe.lastUser = player`。
- **加强**：AxeUpgradeLevel 2→3（金斧，4 伤害/击）。
- **诊断**：每次命中输出树血量变化，SMAPI 控制台可见：`[Woodcutter] Hit tree at (x,y) health: 10→6 stump=False tick=12345`
