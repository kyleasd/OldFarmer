## 自动浇水特性（已推翻重做）
- 之前误以为铱金锄头 `DoFunction` 会自动浇水，是错的。反编译游戏源码确认：`Hoe.DoFunction` 本身不浇水。
- 真正原因：`GameLocation.makeHoeDirt` 创建 `new HoeDirt((IsRainingHere() && isOutdoors) ? 1 : 0, this)`——**雨天耕地时原版就会直接产出浇水状态的地**（`IsRainingHere()` 为 true）。`HoeDirt.tickUpdate` 每帧不会重新浇水，所以问题只在创建瞬间。
- 用户看到的"1-2 帧后才变浇水"是水渍贴图渲染滞后，状态从第 0 帧就是 watered。
- 最终修法：`TillingExecutor.TillArea` 在 `hoe.DoFunction` 之后强制 `dirt.state.Value = HoeDirt.dry`，覆盖雨天自动浇水，保证爷爷耕的地始终干燥需手动浇。
- `HoeDirt` 状态常量：`dry=0`, `watered=1`, 另有 `2`（paddy/特殊）。
- 部署：沙箱拦截写入 Steam Mods 目录，需用户关游戏后手动把 `bin/Release/net6.0/OldFarmer.dll` 覆盖到 Mods/OldFarmer/。

## 修复爷爷在巨大化作物格子上耕地
- 问题：`TillingExecutor.TillArea` 只检查了 `terrainFeatures.TryGetValue`（巨大化作物只有原点 tile 有 TerrainFeature），非原点占用的 8 个格子会被误耕。
- 根因：`TileScanner.IsTillable` 里的修复对实际耕地无效——`TillingExecutor` 有自己的跳过逻辑，根本不调用 `TileScanner`。
- 修法（TillingExecutor）：在 `TillArea` 的 9x9 循环前预建 `occupiedByClumps` Hash Set（遍历所有 `ResourceClump`，按其 `width`/`height` 展开占用的所有格子），循环内跳过被占用的格子。耕地后强制 `state.Value = HoeDirt.dry`（覆盖雨天自动浇水）。
- 顺带优化（TileScanner）：原来 `IsTillable` 每判断一个格子都要遍历所有 terrainFeatures 重建 Hash Set，改为在 `GetUntilledTiles` 里只建一次，通过参数传给 `IsTillable`。新增 `BuildOccupiedByClumps` 辅助方法统一逻辑。
