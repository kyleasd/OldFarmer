# 2026-07-08 工作日志

## 多爷爷召唤功能（Multi-Grandpa Summoning）

### 需求
- 玩家可以多次喝神秘糖浆，召唤多个爷爷
- 爷爷们共用同一条 SAN 体力条
- 最大上限 10 个爷爷

### 架构变更

#### GrandpaSpiritOrbiter.cs
- 移除了 `static Instance` 单例模式（不再需要全局唯一引用）
- 新增 `angleOffset` 构造参数，让多个爷爷在轨道上均匀分布（间隔 90°）
- `GetOrbitOffset()` / `GetOrbitAngle()` 从 static 改为 instance 方法
- `Revive()` 时 `angle` 重置为 `_angleOffset`
- 战斗红色着色（`IsInCombatMode`）从 ModEntry 移入 orbiter 的 Draw 方法中

#### 所有 6 个 Module（Tilling/Watering/Scything/Woodcutting/Planting/Combat）
- 从单 `(behavior, orbiter)` 改为 `List<(behavior, orbiter)>` 模式
- 新增 `AddGrandpa(orbiter)` 方法：创建新 behavior 实例并绑定到给定 orbiter
- 新增 `RemoveAllGrandpas()` 方法：清空列表并重置 orbiter 状态
- `Update()` 遍历所有条目，跳过正在淡出或已销毁的 orbiter
- `Draw()` 遍历所有条目绘制高亮/特效
- `Disable()` 重置所有 behavior 和 orbiter 状态
- 构造函数不再需要 orbiter 参数（PlantingModule 仍需 IMonitor）
- 每个模块保存 `_monitor` 字段，`AddGrandpa` 时传给新 behavior

#### ModEntry.cs
- `private readonly GrandpaSpiritOrbiter grandpaSpirit` → `private readonly List<GrandpaSpiritOrbiter> _grandpas`
- 所有模块构造不再传 orbiter
- `SummonGrandpa()`：
  - 恢复 SAN 到满值
  - 若未达上限（4），创建新 orbiter（angleOffset = count * π/2）并注册到所有模块
  - 显示对应数量提示消息（"又一位爷爷回来了！现在共有 N 位爷爷守护着你。"）
  - 达到上限时提示"爷爷们已经到齐了！"
- `OnUpdateTicked`：
  - `foreach` 更新所有 orbiter
  - `RemoveAll(g => g.IsDestroyed)` 清理已销毁的 orbiter
  - SAN 归零时对所有未淡出的 orbiter 触发 `StartFadeOut()`
  - 全部销毁时清空所有模块并 return
- `OnRenderedWorld`：`foreach` 绘制所有 orbiter
- `OnDayEnding`：`foreach` dismiss 所有 orbiter，`Clear()` 列表，`RemoveAllGrandpas()` 清空所有模块

### 数据流
```
SummonGrandpa()
  → new GrandpaSpiritOrbiter(angleOffset)
  → orbiter.Revive()
  → _grandpas.Add(orbiter)
  → 各 module.AddGrandpa(orbiter)
    → 每个 module 创建独立 behavior 实例

OnUpdateTicked
  → foreach orbiter: Update() (轨道角度+淡出动画)
  → RemoveAll destroyed
  → SAN<=0 → foreach orbiter: StartFadeOut()
  → module.Update() → foreach entry: behavior.Update() + sync to orbiter

OnRenderedWorld
  → foreach orbiter: Draw() (按优先级链选择位置)
  → module.Draw() → foreach entry: draw highlights/effects
```

### 关键设计决策
1. **每个爷爷独立工作**：各自扫描、选目标、执行任务。可能偶尔重复处理同一块地（无害，已耕地重耕是 no-op）
2. **SAN 共享**：`SanManager` 本就是 static + player.modData 存储，天然支持共享
3. **淡出期间不工作**：module.Update 跳过 `IsFadingOut() || IsDestroyed` 的 orbiter
4. **战斗模式全局生效**：CombatModule.Enable 时对所有 orbiter 设置 `IsInCombatMode = true`
5. **轨道分布**：4 个爷爷分别在 0°/90°/180°/270°，同速旋转保持队形
