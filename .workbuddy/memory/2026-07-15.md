# 2026-07-15 工作日志

## 多爷爷耕地分区协调
- **问题**：多个爷爷同时耕地时会选同一个中心点（各自独立扫描得到相同列表）。
- **方案**：引入共享的 `HashSet<Vector2> _claimedCenters`，每个爷爷选目标时排除已被其他爷爷认领的中心点。
- **改动**：
  - `TillingModule`：新增 `_claimedCenters` 字段，`AddGrandpa` 时通过 `behavior.SetClaimedCenters(_claimedCenters)` 注入；`RemoveAllGrandpas`/`Disable` 时清空。
  - `GrandpaTillerBehavior`：
    - 移除 `centerQueue` 队列机制，改为每次只选一个中心点。
    - 新增 `ClaimCenter`/`ReleaseClaim` 方法管理认领/释放。
    - 新增 `TryPickNextTarget` 统一方法（`TickOrbiting` 和 `TickNextTarget` 共用），扫描时过滤 `_claimedCenters` 中的点。
    - `TransitionTo(State.Orbiting)` 和 `Reset()` 中调用 `ReleaseClaim()`。
- **效果**：多个爷爷各自认领不同的 9×9 中心点，耕地范围不重叠。先完成的爷爷会重新扫描获取下一个可用中心点。

## 多爷爷战斗分散策略（SharedTargetManager 软策略）
- **问题**：多个爷爷总是选同一只最近怪物（全部 `monsters[0]`），有多个怪物时不会分散。
- **方案**：战斗用「优先未认领、允许集火」的软策略——有别于农活模块的硬排斥。
- **改动**：
  - `CombatModule`：新增 `_targetMgr = new SharedTargetManager()`，`AddGrandpa` 注入，`Disable`/`RemoveAllGrandpas` 清空。
  - `GrandpaFighterBehavior`：
    - 新增字段 `_targetMgr`、`_claimedMonsterTile`，方法 `SetTargetManager`。
    - `PickBestTarget`: 先遍历 unclaimed 的怪物，全都被认领则 fallback 到最近（集火）。
    - `ClaimTarget` / `ReleaseClaim` 管理认领生命周期。
    - `TickOrbiting` 和 `TickNextTarget` 改用 `PickBestTarget` 选怪。
    - `TransitionTo(Orbiting)` 和 `Reset()` 中释放认领。
- **效果**：3 只怪 + 3 个爷爷 → 各打各的（分散）；1 只怪 + 3 个爷爷 → 围殴（集火）。
