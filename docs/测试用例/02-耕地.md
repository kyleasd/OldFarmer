# 02 - 耕地

## 相关实现
- 触发：`ModEntry` 中玩家手持`锄头 Hoe`
- 行为：`GrandpaTillerBehavior`（扫描 8×8、每次 9×9）
- 执行：`TillingExecutor.TillArea`

## 规则摘要
- 仅在**农场（`IsFarm` 且 `IsOutdoors`）**生效。
- 扫描玩家周围 8×8，寻找未耕且可挖的格子。
- 找到后移动到 9×9 中心 → 蓄力约 0.5 秒（30 tick）→ 一次性耕 9×9。
- 跳过：已有 `HoeDirt`、放置了 `Object`、资源团（巨型作物/大石等）、非 `Diggable` 格子。
- 耕地后强制为**干燥**状态（即使在雨天）。
- 每次 9×9 消耗 **5 SAN**。

---

### TL-01 锄头触发耕地（P0）
- 前置：农场（室外）已召唤爷爷。
- 步骤：手持锄头站立，观察行为。
- 预期：
  1. 爷爷移向某 9×9 中心。
  2. 蓄力阶段地面出现 9×9 高亮网格 + 抖动。
  3. 网格内可耕空地变为干燥的耕地（9×9）。
- 备注：爷爷移动/耕地期间不使用玩家体力。

### TL-02 非农场不触发（P1）
- 前置：手持锄头，位于农场屋内部/城镇/矿洞。
- 步骤：站立观察。
- 预期：不进行耕地；爷爷保持环绕。

### TL-03 已耕/有物/不可挖格子被跳过（P0）
- 前置：农场中在爷爷作用范围内预先放置箱子/机器，及已有耕地、已播作物。
- 步骤：手持锄头触发行耕地。
- 预期：已有耕地、放置物、作物、树/石头等格子不被破坏、不被重复耕。

### TL-04 雨天不自动浇水（P0）
- 前置：选择雨天（或使用 `debug` 切天气）。
- 步骤：手持锄头耕地，耕完后检查土壤状态。
- 预期：新耕的地为**干燥**状态（不会因下雨自动变湿）。

### TL-05 资源团保护（P1）
- 前置：农场内存在大石头/大木桩/巨型作物。
- 步骤：手持锄头在其附近耕地。
- 预期：资源团所在格子不被耕地破坏。

### TL-06 多爷爷分工（P2）
- 前置：召唤 ≥ 3 位爷爷，持有锄头。
- 步骤：站在大片未耕空地上。
- 预期：爷爷们选择不同的 9×9 中心（互不重叠/少重叠），尽快覆盖区域。

### TL-07 耕地消耗 SAN（P1）
- 前置：记录 SAN。
- 步骤：完成一次 9×9 耕地。
- 预期：SAN 减少 5；SAN 不足为负时停止工作。

### TL-08 切换工具停止（P1）
- 前置：爷爷正在耕地。
- 步骤：切换到非锄头物品。
- 预期：立即停止耕地，爷爷回到环绕状态，无卡死/残留高亮。
