# 03 - 浇水

## 相关实现
- 触发：`ModEntry` 中玩家手持`洒水壶 WateringCan`
- 行为：`GrandpaWatererBehavior`（扫描 8×8、每次 9×9）
- 执行：`WateringExecutor.WaterArea`

## 规则摘要
- 仅在**农场（`IsFarm` 且 `IsOutdoors`）**生效。
- 扫描玩家周围 8×8 内**未浇水**的耕地（`HoeDirt.state != 1`）。
- 移动到 9×9 中心 → 准备约 0.33 秒 → 蓄水约 0.3 秒后一次浇 9×9。
- 直接设置土壤为浇水状态并播放水花粒子，**不修改玩家手持工具**（玩家不会出现浇水动作）。
- 播放 `wateringCan` 音效。
- 每次 9×9 消耗 **3 SAN**。

---

### WT-01 洒水壶触发浇水（P0）
- 前置：农场中已有干燥耕地；已召唤爷爷。
- 步骤：手持洒水壶站立观察。
- 预期：
  1. 爷爷移动到 9×9 中心。
  2. 准备阶段地面出现 9×9 高亮。
  3. 一次浇水后，9×9 内所有干燥耕地变为湿润。
  4. 出现水花粒子并播放浇水音效。

### WT-02 玩家无浇水动画（P0）
- 前置：承接 WT-01。
- 步骤：观察玩家角色。
- 预期：玩家角色**不播放**浇水的抬手动画，手持物品不变化。

### WT-03 已浇水格子跳过（P1）
- 前置：一部分耕地已湿润。
- 步骤：手持续浇水壶。
- 预期：湿润格子不重复浇水；爷爷选择仍有干燥耕地的区域。

### WT-04 无干燥耕地时不工作（P1）
- 前置：作用范围内所有耕地已浇水。
- 步骤：手持洒水壶站立。
- 预期：爷爷保持环绕，不来回移动。

### WT-05 浇水消耗 SAN（P1）
- 前置：记录 SAN。
- 步骤：完成一次 9×9 浇水。
- 预期：SAN 减少 3。

### WT-06 非农场不触发（P1）
- 前置：位于温室以外的非农场室外、或矿洞。
- 步骤：手持洒水壶。
- 预期：不浇水。

### WT-07 切换工具停止（P1）
- 前置：爷爷正在浇水。
- 步骤：切换到非洒水壶物品。
- 预期：立即停止，无卡死/残留高亮。
