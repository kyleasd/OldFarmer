# 05 - 收割（镰刀）

## 相关实现
- 触发：`ModEntry` 中玩家手持**镰刀**（`MeleeWeapon` 且 `Name` 含 "Scythe"）
- 行为：`GrandpaScytherBehavior`（扫描 17×17、每次 9×9）
- 扫描：`ScythingScanner`，执行：`ScythingExecutor.HarvestArea`

## 规则摘要
- 仅在**农场（`IsFarm` 且 `IsOutdoors`）**生效。
- 扫描玩家周围 17×17（半径 8）内的目标：
  - 成熟作物（最终生长阶段且未枯死）；
  - 杂草 `Grass`。
- 移动到 9×9 中心 → 蓄力约 0.4 秒 → 一次性收割 9×9。
- **设计行为**：爷爷的镰刀会收割所有成熟作物，**不区分 `harvestMethod`**（即需要手摘的作物也会被收走），与 `ScythingExecutor` 的 "all crops" 说明一致。
- 杂草：优先送入筒仓（`Farm.tryToAddHay(1)`），筒仓不存在/已满时掉落干草 `(O)178`。
- 每次 9×9 消耗 **2 SAN**。

---

### SC-01 镰刀触发收割（P0）
- 前置：农场中有成熟作物 + 杂草；已召唤爷爷。
- 步骤：手持镰刀站立观察。
- 预期：
  1. 爷爷移动到 9×9 中心，蓄力时有高亮网格。
  2. 9×9 内成熟作物被收获（产物进入背包/掉落）。
  3. 9×9 内杂草被清除。

### SC-02 未成熟作物不收割（P0）
- 前置：存在未成熟作物。
- 步骤：手持镰刀。
- 预期：未成熟作物不被收割、不被破坏。

### SC-03 杂草入筒仓（P0）
- 前置：农场有**未满**的筒仓；有多处杂草。
- 步骤：收割杂草。
- 预期：干草直接进入筒仓（筒仓计数增加），地面不产生掉落物。

### SC-04 无筒仓/筒仓已满时掉落干草（P1）
- 前置：无筒仓或筒仓已满。
- 步骤：收割杂草。
- 预期：地面掉落干草物品 `(O)178`，可拾取。

### SC-05 手摘类作物也会被收割（P1，设计说明）
- 前置：存在需要手摘的成熟作物（如草莓/番茄）。
- 步骤：手持镰刀。
- 预期：该作物也会被收割。
- 备注：若你希望恢复原版限制（仅 `harvestMethod == 1` 可用镰刀收），需要修改 `ScythingScanner`，请记录为需求变更。

### SC-06 枯死作物（P1）
- 前置：存在枯死作物。
- 步骤：手持镰刀。
- 预期：枯死作物不会被 `harvest` 收集产物（是否清除以游戏表现为准，不应崩溃）。

### SC-07 收割消耗 SAN（P1）
- 前置：记录 SAN。
- 步骤：完成一次 9×9 收割。
- 预期：SAN 减少 2。

### SC-08 切换工具停止（P1）
- 前置：爷爷正在收割。
- 步骤：切换到非镰刀物品。
- 预期：立即停止，无残留高亮，爷爷回到环绕。
