# 06 - 砍树

## 相关实现
- 触发：`ModEntry` 中玩家手持`斧头 Axe`
- 行为：`GrandpaWoodcutterBehavior`（扫描 17×17）
- 执行：`WoodcutterExecutor.ChopAtPosition`（铜斧，`performToolAction`）
- 修复项：**F5** — 命中冷却字典以前跨场景持久，现按场景清空。

## 规则摘要
- 仅在**农场（`IsFarm` 且 `IsOutdoors`）**生效。
- 扫描玩家周围 17×17 内 `Tree` 且 `growthStage >= 5` 或树桩。
- 爷爷走 **L 形路径**（先水平 X 对齐，再垂直 Y 对齐）。
- 到达后旋转斧头约 **3 秒**（180 tick），斧头触碰到的树即受击。
- 单格命中冷却 **15 tick**；斧头为铜斧（2 点伤害/次）。
- 每摧毁一棵树消耗 **8 SAN**。

---

### WC-01 斧头触发砍树（P0）
- 前置：农场中有成材的树；已召唤爷爷。
- 步骤：手持斧头站立观察。
- 预期：
  1. 爷爷走向最近的树，斧头环绕旋转。
  2. 树被逐次削减并最终倒下（出现木屑、音效、掉落木材/树液）。
  3. 树桩按游戏规则产出/需要额外砍击。

### WC-02 树苗不砍（P0）
- 前置：存在 `growthStage < 5` 的树苗。
- 步骤：手持斧头。
- 预期：树苗不被砍伐。

### WC-03 树桩可砍（P1）
- 前置：场地有树桩。
- 步骤：手持斧头。
- 预期：树桩会被处理。

### WC-04 多目标连续作业（P1）
- 前置：附近有多棵树。
- 步骤：手持斧头。
- 预期：处理完一棵后自动前往下一棵，直到范围内无目标再回到环绕。

### WC-05 【F5】切场景后冷却不残留（P0，回归重点）
- 前置：在农场砍树（制造命中冷却）。
- 步骤：立刻前往其他地图（如矿洞/城镇）再返回农场（或切换两个农场区域）。
- 预期：返回后第一下砍树立即生效，不应因旧坐标冷却而「砍不动」。
- 回归说明：修复前 `LastHitTick` 是全局静态且不随场景清空，换场景同坐标树会被错误冷却。

### WC-06 无树时不工作（P1）
- 前置：范围内无成材树/树桩。
- 步骤：手持斧头。
- 预期：爷爷保持环绕。

### WC-07 砍树消耗 SAN（P1）
- 前置：记录 SAN。
- 步骤：砍倒若干棵树。
- 预期：每棵减少 8 SAN；SAN 归零后停止砍树。

### WC-08 切换工具停止（P1）
- 前置：爷爷正在砍树。
- 步骤：切换到非斧头物品。
- 预期：立即停止，爷爷回到环绕，无残留斧头贴图。
