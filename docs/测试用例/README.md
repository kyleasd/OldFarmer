# OldFarmer（老农民）手动测试用例

本目录用于**在游戏内手动验证** OldFarmer 模组的功能与本次缺陷修复。

## 一、测试环境

| 项目 | 要求 |
| --- | --- |
| 游戏 | Stardew Valley 1.6.x（PC / Steam） |
| SMAPI | 4.0.0 及以上 |
| 模组版本 | OldFarmer 1.2.0（本次修复后需重新编译并部署） |
| 必备物品 | 神秘糖浆 `(O)MysticSyrup`（召唤爷爷用） |
| 可选工具 | 锄头、洒水壶、镰刀、斧头、任意种子、武器 |

> 部署：`dotnet build OldFarmer.csproj` 后，ModBuildConfig 会自动把模组复制到 `Stardew Valley/Mods/OldFarmer`。

## 二、测试准备

1. **备份存档**：复制 `%AppData%\StardewValley\Saves\<存档名>` 到安全位置。
2. **准备物品**：可通过 CJB Item Spawner / 控制台 `debug` 命令或正常游戏流程获取：
   - 神秘糖浆（Mystic Syrup）
   - 各等级工具（锄头 / 洒水壶 / 镰刀 / 斧头）
   - 种子（当季 / 过季各一种）
3. **召唤爷爷**：手持神秘糖浆，按 `右键/使用键` 触发进食动画；进食结束后爷爷出现，SAN 条显示在耐力条左侧。
4. **怪物测试场景**：普通农场夜间、或使用 `debug` 传送到矿洞；也可以开启 `debug` 模式刷怪。
5. **SAN 归零**：多次使用农活让 SAN 降到 0，观察爷爷消失流程。

## 三、记录方式

每个用例包含 **编号 / 前置条件 / 操作步骤 / 预期结果**。测试后请填写文末的「测试记录表」：

- `结果`：`✅ 通过` / `❌ 失败` / `⛔ 阻塞`
- `实际表现`：与预期不一致时详细描述（截图/日志更佳）
- `备注`：复现条件、频率

SMAPI 控制台日志位置：`%AppData%\StardewValley\ErrorLogs\SMAPI-latest.txt`。出现红字异常请先记录再判断。
